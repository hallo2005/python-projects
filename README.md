# Python Projects

A collection of Python projects built while learning core programming concepts — from fundamentals through object-oriented programming.

## Projects

### 🎯 Guessing Game (`guessing_game.py`)
A number guessing game where the player tries to guess a randomly generated number, with feedback on whether their guess is too high or too low.

### 🧠 Quiz Game (`quiz_game.py`)
A multiple-choice trivia quiz with scoring, replayability, and a personalized result message based on performance.

### ✅ To-Do List (`todo_list.py`)
A menu-driven to-do list app that lets users add, view, and remove tasks in an interactive session.

### 🧮 Calculator (`calculator.py`)
A simple calculator supporting addition, subtraction, multiplication, and division, with repeatable calculations and input validation.

### 💰 Budget Tracker (`budget_tracker.py`)
An expense tracker that logs spending by category to a CSV file and calculates running totals — data persists between sessions.

### 🏦 Bank Account System (`bank_account.py`)
A full object-oriented banking simulation featuring:
- Classes and inheritance (`BankAccount` and `SavingsAccount`)
- Encapsulation and protected data
- Deposits, withdrawals, transfers, and interest calculation
- Data persistence via CSV (accounts survive between runs)
- A full interactive menu system

## Skills Demonstrated
- Python fundamentals (variables, loops, conditionals, functions)
- Data structures (lists, dictionaries)
- File I/O (text files and CSV)
- Object-oriented programming (classes, inheritance, encapsulation, polymorphism)
- Debugging and problem-solving

## How to Run
Each project is a standalone Python file. Run any of them with:

\`\`\`
python3 filename.py
\`\`\`

For example:
\`\`\`
python3 bank_account.py
\`\`\`
